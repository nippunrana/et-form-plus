# Form builder plugin (standard + conversational forms)

**Status:** Parked — idea captured, not yet researched or planned in detail.
**Captured:** 2026-11-19

## The idea

A WordPress plugin that helps users create forms.

### Standard forms

Everyday forms such as contact us, sales, etc.

### Conversational forms

- **Multi-Step Form (or Wizard)** — breaks a longer form into sequential screens or steps, typically accompanied by a progress bar.
- **Conversational Form** — presents one question at a time on a full-screen or focused canvas, smoothly transitioning to the next question upon selection.
- **Conditional Logic / Branching Form** — adjusts the next question dynamically based on the user's previous answer. Often combined with conversational forms to create interactive quizzes or lead-qualification funnels.
